How to use it

  1. In Banner, go to your registration schedule and use the Print view — save or export it as a PDF.
  2. Drop that PDF above. Everything happens locally in your browser — the file is never uploaded anywhere.
  3. Check the preview table, then hit Download .ics.
  4. In Google Calendar: Settings → Import & export → Import, and select the downloaded file. (Works in Apple Calendar and Outlook too.)
